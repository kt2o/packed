# Packed App
A cross-platform mobile application for students to find and crowdsource real-time study spot availability on CWRU campus

## Tech Stack
* Frontend: React Native (via Expo)
* Backend: Supabase (PostgreSQL & Authentication)
* Language: TypeScript / JavaScript

---

### 1. Prerequisites
Ensure you have the following installed:
* [Node.js](https://nodejs.org/) (LTS Version)
* [Git](https://git-scm.com/)
* **Expo Go** app (Download on your iPhone or Android device)
